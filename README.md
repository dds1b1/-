这是我这10多天以来通过ai边学边实战爬虫技术的产物
### 我是一边让ai做一边教我学各种爬虫知识，所以成品里面有很多的ai部分（homework1），甚至commit里面还混有ai写的东西，但是我认真写了ai布置给我写的部分，后面的bug我也是一步步先问ai再自己修的，我后面会一步步把ai生成的部分搞明白，求学长大大手下留情。
一，结构：
    1.homework1.py（本体，负责连接调试浏览器，爬数据，加工成csv表格,大部分由ai编写，处理和保存函数是本人在ai辅导下写的）
    2.启动调试浏览器.bat(开启一个有后门的浏览器，用来获取绕过cloud flare的指纹，cookie等信息，完全由ai编写，本人通过ai了解了其工作原理)
    3.day5复现清洗去重.py（用来进一步处理csv里面的数据，去重，整理。大部分由本人在ai指导下编写，备份并输出验证部分由ai完成）
    4.清洗数据.bat（点开直接用的版本，ai改写）
    5.graphql_body_样本.json是 GraphQL 请求体，在homework1里面要用

二，运行方式：（需要playwright）
    1，打开  启动调试浏览器.bat
    2，在弹开的浏览器里面登陆upwork（登谁的都行，第一次登陆可能要开加速器）
    3，点开人才搜索页面（看到人的那个）
    4，在vscode里面运行homework1（千万别关浏览器！）
    5，在vscode里面打开‘清洗去重’并运行，或者打开运行'清洗数据.bat'

三，成果：
    2179 条人员数据 每条有12 字段，包含"person_id", "name", "country", "city", "region","hourly_rate", "job_success", "total_hours","total_earned", "jobs_completed", "description","skills"  无重复数据
    没有2500条是因为去重少了一部分，爬虫是可以一次性出2179条的，不是拼出来的
